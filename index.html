About the handbook

This is a working manual for software and data engineers who want to move from AI autocomplete to genuine agentic engineering.

It focuses on what changes when AI can investigate problems, use tools, modify files, run tests, interpret results and decide what to do next.

What you'll find inside

The handbook combines concepts, practical workflows, prompts, examples, SQL and code, with a strong emphasis on evidence, review discipline, permissions and safe agent operation.
